# personas.txt — 情绪文案表（想改词直接改这里，改完重启面板即可）
#
# 格式：
#   persona|<id>|<显示名>|<强调色>
#   line|<persona>|<触发 key>|<变体号>|<文案>|<emoji>
#
# 占位符（只允许这几个）：
#   {in} 本轮输入 token    {out} 本轮输出 token   {cache} 缓存命中率
#   {credit} 本轮积分      {calls} 本轮调用次数   {today} 今日积分
#   {n} 轮次/数量          {h} 小时数             {name} 人格显示名
#
# 触发 key 一览：
#   firstMeet 首次使用        turnHigh 单轮输入异常    callsHigh 调用次数爆炸
#   creditHigh 单轮花钱多     cacheBest 缓存破纪录     cacheGood 缓存良好
#   cacheBad 缓存崩了         creditMilestone 今日积分里程碑
#   turnsMilestone 累计轮次   degradedToday 今日汇总失败  noTranscript 日志读不到
#   longSession 连续工作      lateNight 深夜            nap 打盹
#   napWake 打盹醒来          sitLong 久坐              newDay 跨天
#   personaSwitch 切换人格反馈  chatty 话痨模式的普通轮次
