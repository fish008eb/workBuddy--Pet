## 4. 状态与情绪的分层规则

- **状态 = 底层循环**：一直播，构成「它在干什么」的底噪。
- **情绪 = 上层一次性**：播完 0.2 s 淡回当前状态，不改变底层状态。
- 同一时刻只播一个动作，不做叠加。

| 优先级 | 层 | 动作 | 起效 |
|---|---|---|---|
| 1（最高） | 打断型 | `error` / `blocked` / `attention` | 0.3 s 内硬切，播完回到原状态 |
| 2 | 情绪 | 7 个 `emo` | 一次性，可被打断型抢占 |
| 3（最低） | 状态 | 9 个 `state` | 常驻循环，被上层覆盖时暂停 |

`sleepy` / `calm` / `sleeping` 三者最容易混，按眼皮与蒸汽分级：
`sleepy` 半合眼 + 下沉 + 尚存一丝蒸汽 → `calm` 睁眼 + 平稳 + 蒸汽匀速 → `sleeping` 全闭眼 + 无蒸汽 + 静止。

| 方式 | 写法 |
|---|---|
| JSON | `frames["tuantuan.state.thinking"]` → `x / y / w / h` 直接喂 `new CroppedBitmap(src, rect)` |

## 7. 注意事项

1. **只有 32 张是有效帧**。`桌宠形象概念稿_assets/` 里共 49 张 PNG：32 张当前帧 + 4 张早期概念稿 + 2 张主形象定稿 + 11 张被替换的旧版动作。定稿图只作为后续派生新素材的参考基准，不进图集。
2. **两只原始体量不同**：团团 trim 约 730×760，可可约 680×850（含较高的蒸汽）。同屏显示时按 trim 宽度做一次等比缩放，否则杯子会明显比猫大。
3. **优先用 2x**：1x 是 2x 降采样，蒸汽这类细线会淡一点；运行时加载 2x 再按显示尺寸缩放更清楚。
4. 改源图或调整帧顺序后，回**仓库外的素材目录**（本项目为 `C:\Users\fish0\WorkBuddy\2026-11-09-10-04-48\pet-atlas\`）重跑 `build_atlas.py`，图集、裁切表、XAML 会一起重出，不用手改坐标。该脚本与该素材目录都不随本仓库、也不随发布包分发。

### 与团团 / 可可的差异

1. **帧间隔乘 `_runSpeed`**：执行工具时吃得快、思考时张望得慢、休眠时整体放慢，复用原来的状态节奏，不额外定义一套速度表。
2. **素材是照片 + 青底**：抠图用「与底色距离」软阈值 + 青色溢色回拉；白毛边缘不会挂绿边，浅色和深色桌面上都验过。
3. **体型按最高帧统一**：六条素材原始缩放差 3 倍以上（主体 1155px 高、扑蝴蝶 344px 高），脚本按每条的最高帧归一到 286px，否则切状态时猫会忽大忽小。
