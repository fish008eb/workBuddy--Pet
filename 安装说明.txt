WorkBuddy 用量宠物 — 安装说明
================================

一个小挂件：屏幕右下角蹲只猫，干活时它会在旁边动来动去，
每轮对话结束响一声、弹个气泡，告诉你这轮用了多少 token、缓存命中多少、
花了多少积分、今天还剩多少预算，偶尔还会说句话。


一、安装前需要什么
------------------
1. Windows 10 或 Windows 11
2. WorkBuddy 桌面版（先启动过一次，让它生成配置）
3. Node.js 18 或更高版本
   下载地址：https://nodejs.org/en/download
   （安装时一路下一步即可，装完关掉所有命令行窗口）


二、怎么装（三步）
------------------
1. 把压缩包解压到任意目录（不要在压缩包里直接双击）
2. 双击  install.cmd
3. 看到 "Done." 就装好了，宠物会出现在屏幕右下角

如果宠物没出现：
   - 重启一次 WorkBuddy，然后随便发一条消息给它
   - 宠物是在会话真正跑起来时才拉起的，不是窗口一打开就出现


三、怎么用
----------
  鼠标移到宠物身上   →  显示用量气泡
  左键拖动           →  换位置（会记住）
  右键               →  换形象 / 人格 / 唠叨程度 / 提示音 / 静音 / 退出

  右键菜单各项：
    换形象      12 套官方 + 4 套本地（团团 / 可可 / 奶盖 / 篮球仔），点一下秒切
    人格        可爱治愈 / 毒舌吐槽 / 克制工程师
    唠叨程度    克制（默认）/ 话痨 / 极简
    提示音      开 / 关 / 试听
    复制今日小结 把今天的用量拼成一段话放进剪贴板，可直接粘进日报
    复制本周小结 按项目汇总本周用量，可直接粘进周报
    项目成本…   看本月每个项目各烧了多少积分、占比多少，
                底部还有一条近 30 天的柱状图
    日预算      不启用 / 50 / 100 / 200 / 500 积分，超 80% 会提醒
    月预算      不启用 / 500 / 1000 / 2000 / 5000 积分，
                并按当前速度告诉你「预计哪天用完」
    静音 1 小时 期间不出声、不弹气泡
    Hide       藏起来 10 分钟
    Exit       彻底退出（下次开 WorkBuddy 会自动回来）

  「实时状态」是什么：
    它不只是每轮结束才说话。WorkBuddy 一思考、一调工具、一报错，
    宠物都会立刻换个动作——平时慢悠悠，干活时节奏变快，
    出错会抖一下，完成会跳两下。鼠标移上去还能看到「执行 Bash · 12s」。

  「等待授权」时会怎样：
    需要你点「允许」的时候，气泡会自己弹出来，写着在等哪个工具、
    要执行什么命令，并响一声。这时左键点一下宠物，就会把 WorkBuddy
    切到前台——不用去任务栏里翻。它不会替你做决定，只是提醒你。


四、常见问题
------------
Q: 双击 install.cmd 提示找不到 Node.js
A: 装 Node.js 后重开一次命令行窗口再试。已装但仍报错，说明没加到 PATH，
   重装 Node.js 并勾选 "Add to PATH"。

Q: 宠物出现了但一直不说话
A: 默认是「克制」档，只在破纪录、烧太多、深夜、久坐、里程碑时开口。
   想每轮都说话，右键 → 唠叨程度 → 话痨。

Q: 没有提示音
A: 右键 → 提示音 → 先点「试听」。如果试听也没声：
   - 检查是否处于「静音 1 小时」
   - 检查系统音量与输出设备
   - 文件缺失：重新解压覆盖 assets\sounds 目录

Q: 数字不对 / 和界面显示的积分不一致
A: 读的是本机会话日志，不是官方账单；对账请以 WorkBuddy 内的记录为准。

Q: 杀毒软件报警
A: 面板会写配置、注册 hooks、后台常驻，行为和脚本病毒相似。
   源码全部在 src\ 目录里，可自行审阅（面板是一个 C# 文件 WbPet.cs，
   编译成 WbPet.exe，没有脚本版）。


五、卸载
--------
双击 uninstall.ps1（或右键 → 使用 PowerShell 运行），
它会关闭宠物、撤销 hooks 注册、删除已安装文件，并把配置备份成
settings.json.bak-<时间戳>。

想回滚配置：把备份文件改名成 settings.json 即可。


六、它到底做了什么（给不放心的同学）
------------------------------------
  1. 把脚本复制到  %USERPROFILE%\.workbuddy\hooks
  2. 在 %USERPROFILE%\.workbuddy\settings.json 里注册 hook：
       SessionStart → 启动宠物
       Stop         → 每轮结束计算用量
       另外 13 个生命周期事件（思考 / 调工具 / 出错 / 完成等）
                    → 转发给宠物自己的本地端口（只监听 127.0.0.1）
  3. 备份原配置
除此之外不改动系统设置，不联网上传任何数据（只有下载形象素材时联网）。
