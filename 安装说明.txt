WorkBuddy 用量宠物 — 安装说明
================================

一个小挂件：屏幕右下角蹲只猫，每轮对话结束响一声、弹个气泡，
告诉你这轮用了多少 token、缓存命中多少、花了多少积分，偶尔还会说句话。


一、安装前需要什么
------------------
1. Windows 10 或 Windows 11
2. WorkBuddy 桌面版（先启动过一次，让它生成配置）
3. Node.js 18 或更高版本
   下载地址：https://nodejs.org/en/download
   （安装时一路下一步即可，装完关掉所有命令行窗口）


二、怎么装（三步）
------------------
1. 把压缩包解压到任意目录（不要在压缩包里直接双击）
2. 双击  install.cmd
3. 看到 "Done." 就装好了，宠物会出现在屏幕右下角

如果宠物没出现：
   - 重启一次 WorkBuddy，然后随便发一条消息给它
   - 宠物是在会话真正跑起来时才拉起的，不是窗口一打开就出现


三、怎么用
----------
  鼠标移到宠物身上   →  显示用量气泡
  左键拖动           →  换位置（会记住）
  右键               →  换形象 / 人格 / 唠叨程度 / 提示音 / 静音 / 退出

  右键菜单各项：
    换形象      12 套官方形象，点一下秒切
    人格        可爱治愈 / 毒舌吐槽 / 克制工程师
    唠叨程度    克制（默认）/ 话痨 / 极简
    提示音      开 / 关 / 试听
    静音 1 小时 期间不出声、不弹气泡
    Hide       藏起来 10 分钟
    Exit       彻底退出（下次开 WorkBuddy 会自动回来）


四、常见问题
------------
Q: 双击 install.cmd 提示找不到 Node.js
A: 装 Node.js 后重开一次命令行窗口再试。已装但仍报错，说明没加到 PATH，
   重装 Node.js 并勾选 "Add to PATH"。

Q: 宠物出现了但一直不说话
A: 默认是「克制」档，只在破纪录、烧太多、深夜、久坐、里程碑时开口。
   想每轮都说话，右键 → 唠叨程度 → 话痨。

Q: 没有提示音
A: 右键 → 提示音 → 先点「试听」。如果试听也没声：
   - 检查是否处于「静音 1 小时」
   - 检查系统音量与输出设备
   - 文件缺失：重新解压覆盖 assets\sounds 目录

Q: 数字不对 / 和界面显示的积分不一致
A: 读的是本机会话日志，不是官方账单；对账请以 WorkBuddy 内的记录为准。

Q: 杀毒软件报警
A: 面板会写配置、注册 hooks、后台常驻，行为和脚本病毒相似。
   源码全部在 src\ 目录里，可自行审阅；不放心可以只装 PowerShell 版
   （删掉 src\WbPet.exe，功能减少「情绪系统」与「提示音」）。


五、卸载
--------
双击 uninstall.ps1（或右键 → 使用 PowerShell 运行），
它会关闭宠物、撤销 hooks 注册、删除已安装文件，并把配置备份成
settings.json.bak-<时间戳>。

想回滚配置：把备份文件改名成 settings.json 即可。


六、它到底做了什么（给不放心的同学）
------------------------------------
  1. 把脚本复制到  %USERPROFILE%\.workbuddy\hooks
  2. 在 %USERPROFILE%\.workbuddy\settings.json 里注册两个 hook：
       SessionStart → 启动宠物
       Stop         → 每轮结束计算用量
  3. 备份原配置
除此之外不改动系统设置，不联网上传任何数据（只有下载形象素材时联网）。
